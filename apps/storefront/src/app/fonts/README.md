Self-hosted brand fonts (latin subset, variable weight), downloaded from Google Fonts:

- `fredoka-latin-var.woff2` — Fredoka (headings), SIL Open Font License 1.1
- `inter-latin-var.woff2` — Inter (body), SIL Open Font License 1.1

Loaded with `next/font/local` in `../layout.tsx` so builds do not depend on network access.
